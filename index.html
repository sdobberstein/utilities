Utilities

Small tools that run in the browser.

⏱️ Countdown timer

Pick a date and time, get a shareable link that counts down to it.

📝 Markdown editor

Write markdown with a live preview. Open, download, copy HTML, print.

🔒 Encrypted message

Encrypt text with a password and share a link; the recipient needs the password to read it.

🎣 Jig weight conversions

Common fishing jig weights in ounces and grams, plus a quick converter.

🃏 Flashcards

Enter both sides of each card, share a link, and study the deck shuffled.

▦ QR code generator

Turn a link or text into a QR code you can download or print.
